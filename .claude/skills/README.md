# Agent skills

`angular-developer/` is the official Angular agent skill, vendored from
https://github.com/angular/skills (commit 2727ba4, 2026-11-06; MIT). It is committed so it works in every
checkout without a global install. To refresh it, copy the folder again from that repository, or use
`npx skills add angular/skills` (which installs globally and symlinks it here instead).
